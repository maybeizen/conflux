# @confluxjs/create-conflux

Scaffold a new Conflux bot project.

## Usage

```bash
bunx create-conflux
```

Follow the prompts to pick a directory and package name. The default template lives under `templates/default`.

## Scripts

| Script                | Description |
| --------------------- | ----------- |
| `bun run build`       | Build CLI   |
| `bun run check-types` | Typecheck   |
| `bun run lint`        | ESLint      |
