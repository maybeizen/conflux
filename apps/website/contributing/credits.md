# Credits

Conflux.js exists because of the ecosystems and communities below. Thank you.

## Fluxer.js

[Fluxer.js](https://fluxer.js.org/) and [`@fluxerjs/core`](https://fluxer.js.org/) power the client, gateway events, and API surface Conflux builds on. Without that SDK and documentation, this meta-framework would not be possible.

## Fluxer

[Fluxer.app](https://fluxer.app/) is the chat platform bots connect to. Thanks to the Fluxer team for the product, docs at [docs.fluxer.app](https://docs.fluxer.app/), and the developer experience around bots and communities.

## CommandKit

Project structure, docs layout, and CLI conventions in Conflux.js are **inspired by [CommandKit](https://commandkit.dev/)**.

Thanks to **[NeplexTech](https://neplextech.com/)** for CommandKit and the patterns many of us learned from it.

Thanks to **[UnderCtrl](https://www.youtube.com/@UnderCtrl)** for popularizing CommandKit-style bot development and helping developers get started with structured Discord (and framework) bots.

## Contributors

Thank you to everyone who opens issues, sends pull requests, tries Conflux in real bots, and improves the docs.

See the [GitHub contributors graph](https://github.com/maybeizen/conflux/graphs/contributors) for the full list.
